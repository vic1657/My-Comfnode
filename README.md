# My-Comfnode

Project custom ComfyUI nodes.

## My原色保光

`My原色保光` 是独立的逐像素颜色恢复节点。请先在工作流中将原图与 AI 打光图对齐，再连接到本节点。打光图是最终底片，其亮度、阴影、对比度、纹理、清晰度和输出尺寸全部保持不变；原图只提供颜色，不参与细节或光照重建。

节点提供 `color_restore_strength` 和 `color_saturation` 两个滑块。前者控制使用多少原图颜色，后者控制颜色浓度；两者都不调整打光图亮度。超出 RGB 色域的强高光只压缩色度，不压缩亮度。

## My细节光影保留

`My细节光影保留` 用于原图与 AI 打光图已由前置节点对齐后的细节恢复。打光图始终是最终底片，节点只从原图迁移缺失的亮度微纹理，不迁移原图颜色、低频明暗或结构轮廓。

节点会自动判断两图局部结构是否一致，并保护新生成的轮廓光、投影边缘、人物外轮廓和错位区域。这样可避免普通高低频回填在头发轮廓产生灰白晕边，或在手臂、衣服边界形成双边和割裂。仅需调节 `detail_restore_strength`；可选的 `detail_restore_mask` 输入中，白色区域恢复细节、黑色区域保持打光图、灰色区域按比例过渡。输出的 `细节恢复区域` 遮罩中，亮处表示实际补回了细节，黑处表示被用户遮罩或内部边缘保护排除。

## My光影高保真细节还原

`My光影高保真细节还原` 是独立的原图底片版本，不修改 `My细节光影保留`。输出的五官、肤色、发丝、衣料、背景纹理、尺寸和透明通道全部来自原图。打光图经过双向光流对齐后只用于提取低频明暗、严格平滑并限幅的光色，以及可信的新高光和阴影边界；打光图人物像素、重绘细节和局部杂色不会进入成片。

`detail_restore_strength` 为 `0` 时逐像素返回原图，为 `1` 时在原图质量上应用完整光影。可选遮罩的黑色区域逐像素保持原图，白色区域应用光影。

## My保存JPG

`My保存JPG` 将 IMAGE 输出保存为 JPEG。默认品质为 `95`、色度采样为 `4:4:4`，用于在保留细节和颜色的同时显著降低全分辨率成片体积；透明区域会在白色背景上合成。

## My光的救赎

`My光的救赎` 使用原图作为最终高分辨率底片，从较低分辨率的 AI 打光图中反求多尺度曝光、硬光边界和光色，再在原图像素上重建光照。AI 图只控制光影，不会被直接放大或迁移纹理；输出尺寸、结构、文字和高频细节均来自原图。默认参数适合先直接使用，局部杂边可提高 `杂边抑制`，弱光缺失可提高 `光影细节` 或 `闭环校准`。

## Nano banana2 API

`Nano banana2 API` 是标准工作流节点。左侧提供 `图像1` 到 `图像14` 共 14 个可选参考图输入口；点击 ComfyUI 顶部运行后调用接口，并从右侧输出 `生成图片`、`任务状态` 和 `任务ID`。支持默认、0.5K、1K、2K、4K 分辨率以及自动和常用宽高比。

## 遮罩先后判断

`遮罩先后判断` 提供自动增长的遮罩输入接口。默认显示 `mask0`，连接当前最后一个接口后会自动出现下一个，最多支持 50 个。节点按数字顺序选择第一个包含实际白色区域的遮罩，因此可以把手动画遮罩接在前面、模型自动识别遮罩接在后面；手动画遮罩为空时会自动使用后续遮罩。未连接的动态接口和空白遮罩不会报错，输出只有一个 `优先遮罩`。

## 图像遮罩画笔

`图像遮罩画笔` 保留常用加载图像节点的图片选择、上传、`IMAGE` 和 `MASK` 输出，并允许直接在节点预览图上绘制遮罩。鼠标移动到预览区左上角时显示 `遮罩画笔` 按钮，点击后可选择圆形或方形画笔，并调节画笔大小和透明度；面板还提供本次编辑的 `撤销` 与 `清除` 功能。

每次落笔后遮罩会自动保存到 ComfyUI 输入目录的 `my-mask-brush` 子目录。工作流执行和保存会等待当前遮罩写入完成，重新打开工作流时会恢复已经绘制的遮罩。切换加载图像会自动清空上一张图的遮罩，避免尺寸和内容串用。

## My自定义光源渲染

`My自定义光源渲染` 保留 Sphere Light Render 的球体、地面与实时阴影组件，并将全部控制放在预览下方。`光源方向`、`光源高度`、`光照强度`（最高 6.0）、颜色面板、色相和透明度均在拖动过程中逐帧更新，不需要等待鼠标松开。

节点输出 1024 x 1024 的 `渲染图`，并通过独立的 `颜色信息` 字符串输出标准 `rgba(r, g, b, a)` 文本。节点位于 `My-Comfnode/图像处理`，界面与输入输出名称均为中文。

## My Paint Tool

`My画笔工具` is the integrated canvas paint node imported from the previous `My_node` workflow. It keeps the existing outputs:

- `painted_image`
- `mask`
- `preview`

The previous paint editor node has been removed from this package.

## Fixed Size Image Nodes

This package also keeps the existing fixed-size crop, fixed-size pad, and background-border crop nodes under `My-Comfnode/图像`.
